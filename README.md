# 👾 Cyber Defense - Omega Virus Flowey Edition

Un minijuego de ciberseguridad interactivo inspirado en la épica batalla de **Omega Flowey** en *Undertale*.

## 📁 Estructura del Proyecto

* `index.html` - Estructura semántica HTML5 con overlays CRT y contenedores.
* `styles.css` - Estilos CSS3 retro-cyberpunk, efectos CRT, animaciones físicas de caída y botones neumórficos neon.
* `audio.js` - Sintetizador de audio con Web Audio API (alarmas, láseres, risa macabra, risas y efectos pop).
* `boss.js` - Motor gráfico Canvas HTML5 con la animación cinemática y patrones de ataque de Omega Flowey.
* `game.js` - Lógica de estados del juego, caída física de respuestas, tormenta adware de 20s y botón escapista.

## 🚀 Despliegue en GitHub Pages

1. Sube todos los archivos (`index.html`, `styles.css`, `audio.js`, `boss.js`, `game.js`) a tu repositorio de GitHub.
2. Vé a **Settings** > **Pages** en tu repositorio.
3. Selecciona la rama `main` y guarda.
4. ¡Listo! Tu juego estará publicado en vivo en pocos segundos.
